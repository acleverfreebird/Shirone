# 博客重新上线：从 Typecho 迁移到 Astro

这是博客换到新框架后的第一篇文章，简单记录一下这次迁移。

## 🚀 为什么要换掉 Typecho

作为一个喜欢折腾技术的高中生，我之前一直用 Typecho 搭博客。Typecho 虽然够用，但用久了还是觉得有些地方不够顺手：

- 动态页面加载速度一般，还得一直维护 PHP 和数据库环境
- 现有主题看腻了，想自己改前端样式又比较束手束脚
- 插件管理比较零散

## ⚡ 为什么选 Astro

对比了一圈静态站点生成器后，最后选了 **Astro** 来重构博客：

### 技术优势
- **超快的性能**: 零JavaScript运行时，页面加载速度极快
- **现代化架构**: 支持多种前端框架集成
- **SEO友好**: 静态生成，搜索引擎优化效果更佳
- **开发体验**: 优秀的开发工具链和类型支持

### 功能特性
- 响应式设计，完美适配各种设备
- 暗色/亮色主题切换
- 内置搜索功能
- RSS订阅支持
- 代码高亮和数学公式渲染
